# Описание конфликта

## Где возник конфликт

Конфликт возник в файле `project-notes.md`, в разделе «Открытые вопросы»,
в строке про выбор хранилища данных.

## Почему возник

Две ветки (`fix/conflict-demo` и `feature/notes-update`) были созданы от
одного общего состояния `main` и независимо изменили одну и ту же строку
по-разному:

- `fix/conflict-demo` изменила строку на «Хранилище: SQLite (решено)»
- `feature/notes-update` изменила строку на «Хранилище: PostgreSQL (выбрано)»

При слиянии второй ветки в `main` Git не смог автоматически определить,
какую версию оставить, поскольку обе ветки меняли один и тот же участок.

## Как выглядел конфликт

```
<<<<<<< HEAD
- Хранилище: SQLite (решено).
=======
- Хранилище: PostgreSQL (выбрано).
>>>>>>> feature/notes-update
```

## Как был разрешён

Конфликт разрешён вручную: выбран вариант `SQLite` как более простой
для учебного проекта (не требует отдельного сервера). Маркеры конфликта
удалены, оставлена строка с SQLite.

Разрешение зафиксировано отдельным коммитом:
`merge: resolve storage conflict in favor of SQLite`

## Вывод

Конфликт — это не ошибка, а штатная ситуация при совместной работе.
Git останавливается и просит человека принять решение, после чего
сохраняет результат как обычный коммит.
