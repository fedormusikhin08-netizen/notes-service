# План REST API

## Endpoints

| Метод | Путь          | Описание              |
|-------|---------------|-----------------------|
| GET   | /notes        | список заметок        |
| POST  | /notes        | создать заметку       |
| GET   | /notes/{id}   | получить одну заметку |
| PUT   | /notes/{id}   | обновить заметку      |
| DELETE| /notes/{id}   | удалить заметку       |
| GET   | /notes/search | поиск по заголовку    |

## Аутентификация

Планируется базовая авторизация по токену (Bearer token) для доступа к заметкам.

## Формат данных

Заметка описывается полями: `id`, `title`, `text`, `created_at`.
