# Рабочие заметки проекта

## Идея

Разработать сервис заметок: пользователь создаёт заметки, они хранятся
и доступны для просмотра и поиска.

## Ключевая функциональность

- создание заметки (заголовок + текст)
- просмотр списка заметок
- редактирование заметки
- удаление заметки
- поиск по заголовку

## Открытые вопросы

- Хранилище: SQLite (решено).
- Нужна ли авторизация пользователей?
- Будет ли мобильная версия?
