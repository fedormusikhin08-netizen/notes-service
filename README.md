# Сервис заметок

Простой сервис для создания и управления личными заметками.

## Описание

Приложение позволяет пользователю создавать текстовые заметки, редактировать,
удалять и искать их. Основная цель — быстро фиксировать мысли и не терять их.

## Технологии

- Язык: Python (FastAPI)
- Хранение: SQLite
- Фронтенд: планируется позже

## Структура проекта

- `README.md` — описание проекта (этот файл)
- `project-notes.md` — рабочие заметки команды
- `api-plan.md` — план REST API
